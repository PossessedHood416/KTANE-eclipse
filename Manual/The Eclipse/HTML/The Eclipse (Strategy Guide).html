On the Solving Process of The Eclipse

You understand mechanical hands are the ruler of everything.

In order to solve for when an eclipse occurs, it is useful to model the orbits of the two celestial bodies.

An orbit can be modeled by two non-parallel 3D vectors. To convert a 3D vector to and from representations using (δ,θ,φ) or (x,y,z), see below.

x = cos(θ)*cos(φ)*δ
y = cos(θ)*sin(φ)*δ
z = sin(θ)*δ
θ = asin(z/δ)
φ = atan2(y/δ, x/δ)
δ = sqrt(x^2 + y^2 + z^2)

To model a body's orbit, find where the body's distance is at a minimum and maximum (or both extrema). From these, generate 2 3D vectors, these will be refered to as ExC and ExD, where ExC is the one that occurs first with respect to time. Note TInit as time at which a body is at ExC. The position of a body at any given time T can be modeled using the following formulas. For celestial body A, V = 1. For celestial body B, first concatenate the digits of the serial number. If it is a square number, repeatedly add 1 until it isn't. V is the square-root of that number.

Position = ExC*cos(U) + ExD*sin(U)
U = (T - TInit) * V

An eclipse will occur when the position vectors of the bodies point in the same direction. This occurs when the following formula is true.

APosition/Aδ ≈ BPosition/Bδ

Once some T is found such that the above statement is true, use the position vectors to find θ and φ for both bodies. Set T, θ, and φ to the found values to solve the module.

Solving Process Cont.

It should be noted that since the orbits of the bodies are not on the same plane, this can only occur in two specific directions.

P = (AExC ⨯ AExD) ⨯ (BExC ⨯ BExD)
Direction = ± P/|P|

Since orbits are cyclical, the final answer TFinal will adhear to the following, where TDir is the time when APosition = Direction*Aδ is true and k is some positive integer.

TFinal = TDir + 2π*k

Start with k=0 and increment it until body B eclipses with body A.
